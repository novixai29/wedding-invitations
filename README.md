# بداية عمر — دعوات زفاف

ثلاثة نماذج مستقلة بصريًا، مستوحاة من تجربة الظرف في الريبو الأصلي https://github.com/novixai29/dr.fatima- . لم يتم تعديل الريبو الأصلي. الصور والموسيقى من ملفات المصدر التي وفرها صاحب المشروع. لم يُنسخ ملف CNAME حتى يبقى النطاق الأصلي دون تغيير.

## الروابط

- `index.html` معرض النماذج.
- `?invite=midnight` عمر ونور — كحلي وذهبي.
- `?invite=rose` يوسف ومريم — خمري ولؤلؤي.
- `?invite=emerald` علي وزينب — زمردي وذهبي.

**جميع الأسماء والمواعيد والأماكن تجريبية وليست بيانات مناسبة مؤكدة.**

## تخصيص دعوة

عدّل بياناتها في `invitations.js`: الأسماء، الحروف، الموعد بصيغة ISO مع المنطقة الزمنية، القاعة، المدينة، عبارة البحث في الخريطة، والعائلتين. بعد التأكد من البيانات اجعل `demo: false`. التوقيت المعروض والعداد يقرآن نفس التاريخ. التوقيت الافتراضي للعراق.

استبدل `assets/photo1.jpg` و`assets/photo2.jpg` بالصور المطلوبة، و`assets/music.mp3` بالموسيقى المطلوبة. التشغيل يبدأ بعد ضغط فتح الدعوة ويمكن إيقافه بالزر. كل دعوة تعمل من رابطها مباشرة؛ لا يظهر معرض التصاميم لضيوف الرابط المباشر.

## التشغيل والنشر

موقع HTML/CSS/JavaScript ثابت دون بناء أو حزم. يمكن فتح `index.html` مباشرة أو تشغيل `node preview.cjs` للمعاينة على http://localhost:4173 . يدعم GitHub Pages من جذر فرع main. الخطوط فقط تحتاج اتصال إنترنت ولها بدائل محلية. لا توجد نماذج لجمع بيانات الضيوف.

يحترم إعداد تقليل الحركة، يدعم لوحة المفاتيح، ويوقف العد التنازلي عند صفر.
